# تحدي الأبطال | منصة عبقري للحساب الذهني والسوروبان

تطبيق تدريبي تفاعلي للحساب الذهني، يتيح للمتعلم خوض تحديات متدرجة والتدرب على العمليات الحسابية وفق مراحل المنهج.

## تشغيل المشروع محليًا
1. نزّل ملف `index.html`.
2. افتحه باستخدام متصفح حديث مثل Chrome أو Edge.
3. يحتاج الاتصال بالإنترنت لتحميل Tailwind CSS والخطوط والأيقونات من خدمات CDN.

## النشر
- **Netlify:** ارفع مجلد المشروع أو ملف `index.html` عبر صفحة Netlify Drop.
- **GitHub Pages:** ارفع `index.html` إلى مستودع GitHub، ثم فعّل Pages من إعدادات المستودع واجعل مصدر النشر من الفرع الرئيسي والجذر.
